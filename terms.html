利用規約

最終更新日: 2026年7月16日

本規約は、個人開発者(以下「開発者」)が開発するTikTok API連携アプリケーション 「AI実況動画投稿」(以下「本アプリ」)の利用条件を定めるものです。 本アプリは現在開発・動作検証(Sandbox環境)のために提供されており、 一般公開・商用サービスとしての提供は行っておりません。

1. アプリの概要

本アプリは、開発者が運営するTikTokアカウント「中国うさぎ@Live配信でAI実況」(@ai-deliv-usagi)に関連する動画コンテンツを、 TikTok Content Posting API等を通じて投稿・管理するための開発者個人向けツールです。 不特定多数のユーザーへの提供を目的としたものではありません。

2. 利用資格

本アプリ(Sandbox環境)は、開発者本人およびTikTok Developer Portal上でテストユーザーとして 登録されたアカウントのみが利用できます。

3. 禁止事項

本アプリの利用にあたり、以下の行為を禁止します。

  • TikTokの利用規約・コミュニティガイドラインに違反するコンテンツの投稿
  • 本アプリのリバースエンジニアリング、不正アクセス、脆弱性の悪用
  • 取得したAPIアクセス権限を本来の開発・検証目的以外に使用する行為
  • 法令に違反する行為

4. 免責事項

本アプリは開発・検証段階のツールであり、動作の完全性・継続性・特定目的への適合性を保証しません。 本アプリの利用により生じたいかなる損害についても、開発者は故意または重過失がある場合を除き責任を負いません。

5. サービスの変更・停止

開発者は、事前の通知なく本アプリの内容変更、提供の中断、または提供の終了を行うことがあります。

6. 規約の変更

本規約は、本アプリの開発状況(Sandboxから本番環境への移行等)に応じて予告なく変更される場合があります。 変更後の内容は本ページに掲載した時点で効力を生じるものとします。

7. 準拠法

本規約の解釈にあたっては、日本法を準拠法とします。

8. お問い合わせ

本規約に関するお問い合わせは、本リポジトリの GitHub Issues までお願いいたします。
