プライバシーポリシー

最終更新日: 2026年7月16日

本ページは、個人開発者(以下「開発者」)が開発するTikTok API連携アプリケーション 「AI実況動画投稿」(以下「本アプリ」)におけるプライバシーポリシーです。 本アプリは現在開発・動作検証(Sandbox環境)のために開発されているものであり、 一般公開・商用サービスとしての提供は行っておりません。

対象アプリAI実況動画投稿(Sandbox環境)

2. 取得する情報

本アプリはTikTok API(Login Kit・Content Posting API)を通じて、以下の情報のみを取得します。

取得情報取得元スコープ / 機能用途
TikTokアカウントの基本プロフィール情報(ユーザー名、アイコン画像等) Login Kit(OAuth認証) / user.info.basic 本アプリを通じたTikTokアカウントへのログイン認証、および投稿主体の識別
本アプリを通じてアップロードする動画コンテンツおよびその投稿ステータス Content Posting API / video.upload 動画コンテンツを下書き(Draft)としてTikTokの受信箱にアップロードする機能。 最終的な投稿操作はTikTokアプリ側でクリエイター自身が行う。
本アプリを通じて投稿する動画コンテンツおよびその投稿ステータス Content Posting API / video.publish 動画投稿機能(自動クリップ投稿・Direct Post)の開発・動作検証。TikTok側の審査(Audit) 通過後は選択した公開範囲での投稿が行われる。審査完了までの投稿は非公開(Private)扱いに 制限される。

上記以外の個人情報(氏名、メールアドレス、位置情報、連絡先リスト等)を取得することはありません。

なお、本アプリのログイン機能(Login Kit)は、開発者自身が運営するTikTokアカウント 「中国うさぎ@Live配信でAI実況」(@ai-deliv-usagi)を本アプリと連携させるための認証機能であり、 不特定多数の一般ユーザーに向けたログインサービスを提供するものではありません。

3. 利用目的

  • TikTok APIとの連携機能(動画自動投稿)の開発・デバッグ・動作検証
  • Sandbox環境における投稿フローのテスト

取得した情報を上記以外の目的(広告配信、第三者への販売・提供、プロファイリング等)に利用することはありません。

4. 第三者提供

取得した情報を第三者に提供・共有することはありません。ただし、法令に基づき開示を求められた場合はこの限りではありません。

5. データの保存・削除

取得したアクセストークンおよびプロフィール情報は、開発者が管理するクラウド環境(Google Cloud Platform)内に、 動作検証に必要な期間のみ保存します。ユーザーはいつでも開発者に連絡することで、保存されたデータの削除を requestできます。 また、TikTok側の連携解除(アプリ連携の取り消し)によりアクセス権は即時に無効化されます。

6. Cookie等のトラッキング技術

本ページ・本アプリはCookieや類似のトラッキング技術を使用していません。

7. プライバシーポリシーの変更

本ポリシーの内容は、本アプリの開発状況(Sandboxから本番環境への移行等)に応じて予告なく変更される場合があります。 変更後の内容は本ページに掲載した時点で効力を生じるものとします。

本ポリシーおよび本アプリのデータ取り扱いに関するお問い合わせは、本リポジトリの GitHub Issues までお願いいたします。
